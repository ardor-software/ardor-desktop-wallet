## Install

<details open>
<summary><img height="22" src="https://img.shields.io/badge/platform-Windows-3e83be?style=flat-square&labelColor=0c395d&logo=data:image/svg+xml;base64,PHN2ZyB4bWxucz0naHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmcnIHZpZXdCb3g9JzAgMCAyNCAyNCc%2BPHBhdGggZmlsbD0nI2ZmZmZmZicgZD0nTTAgMy42IDkuNCAyLjN2OUgwek0xMC42IDIuMSAyNCAwdjExLjNIMTAuNnpNMCAxMi43aDkuNHY5TDAgMjAuNHpNMTAuNiAxMi43SDI0VjI0bC0xMy40LTEuOXonLz48L3N2Zz4%3D&logoColor=white" alt="Windows"></summary>

1. Download `ardor-wallet-2.6.5.exe` from the button above.
2. Run the installer and follow its prompts. Windows may ask you to confirm the publisher.
3. Start Ardor Wallet from the Start menu.
4. On first launch, choose the full client or the light client.
5. Write the passphrase or seed down before the account holds anything.

</details>

<details>
<summary><img height="22" src="https://img.shields.io/badge/platform-macOS-3e83be?style=flat-square&labelColor=0c395d&logo=apple&logoColor=white" alt="macOS"></summary>

1. Download `ardor-wallet-2.6.5.sh`.
2. Open Terminal in the folder that holds the file: `cd ~/Downloads`
3. Start the installer: `sh ardor-wallet-2.6.5.sh`
4. Follow the prompts, then open the wallet from the folder it created.
5. Choose the client mode and write the secret down before funding the account.

</details>

<details>
<summary><img height="22" src="https://img.shields.io/badge/platform-Linux-3e83be?style=flat-square&labelColor=0c395d&logo=linux&logoColor=white" alt="Linux"></summary>

1. Download `ardor-wallet-2.6.5.zip`.
2. Unpack it: `unzip ardor-wallet-2.6.5.zip -d ardor-wallet`
3. Start the launcher inside the unpacked folder.
4. Choose the client mode, then write the passphrase or seed down.

</details>

Check a download before running it: `certutil -hashfile ardor-wallet-2.6.5.exe SHA256` on Windows, `shasum -a 256 ardor-wallet-2.6.5.sh` on macOS, `sha256sum ardor-wallet-2.6.5.zip` on Linux.

## Features

- Self-custody: the keys are generated and kept on your machine, and no server holds them.
- One passphrase or seed opens ARDR and every Ardor child chain, each with its own balance and history.
- Forging and leasing: start forging, or lease the weight to another account and keep the coins.
- Coin exchange and asset exchange with order books, inside the wallet.
- Issue an asset with royalties, pay dividends to every holder, and trade the result.
- Marketplace listings, on-chain polls, phased and atomic transactions, and multisig.
- Data cloud storage, document timestamps, coin shuffling, aliases and account properties.
- Ledger and Trezor hardware support, so a signature needs the device.
- Full client for a local copy of the chain, light client for a fast start from remote nodes.

---

## Chains and client modes

The wallet opens the ARDR parent chain and its child chains: Ignis, the Nxt child chain, Bitswift and Triffic. Aliases, account properties and issued assets are global, so an asset issued on one chain is reachable from the others.

A full client downloads and validates the chain locally, which forging requires. A light client keeps no chain data and reads balances from remote nodes, which starts in seconds but can show a stale balance while those nodes catch up. The mode can be changed after installation.

---

## Where things live

On Windows the blockchain database sits in `C:\Users\USERNAME\AppData\Roaming\Ardor\nxt_db`. In the Linux archive it is the `nxt_db` folder inside the unpacked package. A light client creates no chain database at all.
